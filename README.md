# Meu Ambiente

Aplicativo de monitoramento ambiental desenvolvido como projeto acadêmico para a disciplina de **Desenvolvimento Mobile**.

## 1. Sobre o projeto

O Meu Ambiente é um projeto que reúne um aplicativo mobile e um firmware para ESP32.

O objetivo é aplicar conhecimentos de desenvolvimento mobile, programação embarcada e integração entre software e hardware.

## 2. Tecnologias utilizadas

- React Native
- Expo
- TypeScript
- Arduino
- Git e GitHub

## 3. Firmware

O firmware está localizado em `firmware/firmware.ino`.

As instruções específicas de configuração e gravação do microcontrolador podem ser consultadas em `firmware/README.md`.
